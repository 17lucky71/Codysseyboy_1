# 🤖 [프로젝트 2] AI 연동 자동 분류 및 디스코드 알림 파이프라인 설계

## 1. 반복 업무 정의 및 자동화 목적
* **반복 업무:** 매일 수신되는 고객/팀 문의 이메일을 직접 확인하고, 내용 파악 후 시트에 기록 및 담당자에게 디스코드/Slack 메시지를 전달하는 업무
* **소요 시간:** 일일 평균 30~50분 소요
* **자동화 목적:** 수신 메일을 AI(OpenAI GPT-4o)가 자동으로 3줄 요약 및 긴급도(High/Low)로 분류하여, 긴급 건은 디스코드 채널로 즉시 알림을 발송하고 Google Sheets에 데이터를 누적 적재하여 처리 효율을 극대화함

---

## 2. 도구 선정 및 선정 이유
* **선정 도구:** **Make**
* **선정 이유:** 
  1. OpenAI 모듈 지원이 우수하여 프롬프트 설정 및 텍스트 구조화가 용이함
  2. 무료 플랜(월 1,000 Operations) 내에서 제한 없이 시각적 Router(조건 분기) 및 다단계 Action 연결이 가능함
  3. Discord Webhook과의 연동 설정이 매우 단순하고 실시간 실행 로그 점검이 편리함

---

## 3. 워크플로우 설계 (Workflow Architecture)
[Trigger: Gmail - Watch Emails]
│
[Action 1: OpenAI GPT-4o] (본문 요약 및 카테고리/긴급도 분류)
│
[Router (조건 분기)]
├── 경로 A (긴급 - High) ──> [Google Sheets 적재] ──> [Discord Webhook 알림 발송]
└── 경로 B (일반 - Low)  ──> [Google Sheets 적재]

---

### 상세 단계 설명
1. **Trigger:** `Gmail - Watch Emails` (Inbox에 새 이메일 수신 시 자동 실행)
2. **Action 1 (AI 연동):** `OpenAI - Create a Completion`
   * 이메일 본문을 분석하여 `[카테고리 / 3줄 요약 / 긴급도(High/Low)]` 데이터 추출
3. **Router (Filter):** 긴급도 필터링
   * **Route A (High):** 긴급도가 High인 건
   * **Route B (Low):** 긴급도가 Low인 건
4. **Action 2:** `Google Sheets - Add a Row` (수신일자, 발신자, 요약, 긴급도 저장)
5. **Action 3:** `Discord Webhook - Send a Message` (Route A 통과 건에 대해 디스코드 알림 전송)

---

## 4. 예외 처리 및 에러 핸들링 (보너스 과제)
* **실패 알림:** OpenAI API 오류나 네트워크 문제로 노드 실행 실패 시 `Error Handler`가 작동하여 관리자 이메일로 실패 알림 메시지를 자동 발송하도록 설계함
