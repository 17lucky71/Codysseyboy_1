## 1. 개요

**Make (Integromat)** 와 **Zapier** 는 현재 가장 인기있는 No-Code 자동화 플랫폼입니다. 본 문서는 두 플랫폼의 특징, 성능, 비용, 사용 난이도를 상세히 비교합니다.

### 핵심 차이점

| 항목 | Make | Zapier |
|------|------|--------|
| **인터페이스** | 노드식 (2D 캔버스) | 단계식 (선형) |
| **응답속도** | 5초 (Webhook) | 2-3분 (Polling) |
| **조건 분기** | 무한 (Router) | 제한적 (Paths) |
| **난이도** | 중간 | 낮음 |

## 2. 아키텍처 비교

### 2.1 Make 아키텍처

Trigger (Gmail, Forms, etc.)
↓
Module 1 (데이터 처리)
↓
Module 2 (API 호출)
↓
Router (조건 분기)
├─ Route A (조건 만족)
│ ├─ Action 1
│ └─ Action 2
└─ Route B (기본값)
└─ Action 3
↓
완료


**특징:**
- ✅ 노드식 인터페이스 (시각적, 복잡한 흐름 가능)
- ✅ 무한 분기 가능 (Router 모듈)
- ✅ JSON 데이터 처리 뛰어남
- ✅ Error Handler로 예외 처리 가능

### 2.2 Zapier 아키텍처

Trigger (Gmail, Forms, etc.)
↓
Step 1 (API 호출)
↓
Step 2 (Paths - 조건 분기)
├─ Path A (조건 만족)
│ └─ Action 1
└─ Path B (기본값)
└─ Action 2
↓
완료


**특징:**
- ✅ 단계식 인터페이스 (마법사식, 초보자 친화적)
- ✅ Paths로 기본 분기 가능
- ✅ 5,000+ 앱 통합
- ✅ 높은 신뢰성

## 3. 성능 분석

### 3.1 응답 속도

Make (Webhook 기반)
┌─────────────────┐
│ 이메일 수신 │
│ ↓ 0초 │
│ 분석 처리 │
│ ↓ +2초 │
│ 결과 저장 │
│ ↓ +1초 │
│ 총 5초 │
└─────────────────┘

Zapier (Polling 기반)
┌─────────────────┐
│ 이메일 수신 │
│ ↓ │
│ 폴링 대기 │
│ ↓ 2~3분 │
│ 분석 처리 │
│ ↓ +2초 │
│ 총 2~3분 │
└─────────────────┘


### 3.2 처리량

| 기준 | Make | Zapier |
|------|------|--------|
| **1시간당** | 720건 | 20~30건 |
| **1일** | 17,280건 | 500~700건 |
| **1개월** | 518,400건 | 15,000~21,000건 |

## 4. 비용 분석

### 4.1 월별 가격 비교

| 플랜 | Make | Zapier |
|------|------|--------|
| **무료** | 1,000 ops/월 ✅ | 100 tasks/월 (2-step) ⚠️ |
| **Basic** | $9.99/월 (10K ops) | $24.99/월 (750 tasks) |
| **Pro** | $18.99/월 (50K ops) | $99/월 (5K tasks) |
| **Enterprise** | 맞춤형 | $299+/월 |

### 4.2 실제 비용 사례

**시나리오: 일일 200건 자동화 (연 50,000건)**

Make 무료 플랜
├─ 월 1,000 ops × 12 = 12,000 ops
├─ 필요: 50,000 ops
├─ Basic (10K ops) × 5개월 필요
└─ 예상 비용: $50/년

Zapier 무료 플랜
├─ 월 100 tasks × 12 = 1,200 tasks
├─ 필요: 50,000 tasks
├─ Pro (5K tasks) × 10개월 필요
└─ 예상 비용: $990/년


**Make가 약 20배 저렴!**

## 5. 도입 가이드

### 5.1 Make를 추천하는 경우

✅ 실시간 응답이 중요할 때
✅ 복잡한 조건 분기가 필요할 때
✅ 대량 자동화 (1,000+ ops/월)
✅ 비용 최적화가 중요할 때
✅ 데이터 변환이 복잡할 때

**예시:**
- AI 연동 파이프라인
- 실시간 알림 시스템
- 복잡한 데이터 처리

### 5.2 Zapier를 추천하는 경우

✅ 빠른 구축이 필요할 때
✅ 많은 앱 통합이 필요할 때
✅ 기술 지식이 부족할 때
✅ 엔터프라이즈급 지원이 필요할 때
✅ 간단한 자동화 (100 tasks/월 이내)

**예시:**
- 간단한 폼 → 이메일 알림
- 소셜 미디어 공유 자동화
- CRM 통합
