# 📊 [프로젝트 1] 노코드 자동화 도구 비교 분석 보고서

## 1. 개요 및 워크플로우 주제
본 보고서는 동일한 자동화 워크플로우를 서로 다른 2개의 대표 노코드 자동화 도구(Make, Zapier)로 구현하고, 각 도구의 특징, 장단점 및 사용 편의성을 다각도로 비교 분석한 문서입니다.

* **워크플로우 주제:** Google Forms 응답 접수 ➡️ 조건 분기(우선순위/점수) ➡️ Google Sheets 적재 + Slack/Discord 알림 전송

---

## 2. 도구별 워크플로우 구성 요약

### 🟣 Make (구 Integromat)
* **Trigger:** Google Forms - *Watch Responses* (신규 응답 감지)
* **Router (조건 분기):** 
  * `Route A (우선순위 High)`: 점수 80점 이상 또는 긴급 문의
  * `Route B (우선순위 Normal)`: 점수 80점 미만 또는 일반 문의
* **Action 1:** Google Sheets - *Add a Row* (선택된 시트에 데이터 저장)
* **Action 2:** Discord / Slack - *Send a Message* (팀 채널 알림 발송)

### 🟠 Zapier
* **Trigger:** Google Forms - *New Response in Spreadsheet*
* **Paths (조건 분기):**
  * `Path A`: Score Greater than or equal to 80
  * `Path B`: Score Less than 80
* **Action 1:** Google Sheets - *Create Spreadsheet Row*
* **Action 2:** Discord / Slack - *Send Channel Message*

## 3. 세부 비교 분석 (5가지 주요 항목)

| 비교 항목 | Make (Integromat) | Zapier |
| :--- | :--- | :--- |
| **1. UI/UX 및 워크플로우 형태** | **시각적 노드(Node) 방식:** 2차원 캔버스 위에서 마우스 드래그 앤 드롭으로 흐름을 직관적으로 배치 가능 | **선형 리스트(Step) 방식:** 위에서 아래로 내려가는 수직적 스텝 구조로 심플하고 직관적 |
| **2. 설정 난이도 및 학습 곡선** | **중~상:** 데이터 매핑 구조(JSON 데이터 패킷) 이해가 필요하여 초기 학습 시간이 일부 요구됨 | **하:** 가이드가 매우 잘 되어 있어 초보자도 5분 내 첫 플로우 구축 가능 |
| **3. 연동 서비스 범위** | **매우 넓음 (1,500+개):** 세부 API 파라미터 제어 및 HTTP 커스텀 요청 모듈 지원 우수 | **최상 (5,000+개):** 현존하는 거의 모든 SaaS 플랫폼 지원, 연결 설정 간소화 |
| **4. 무료 플랜 정책** | **월 1,000 Operations / 분기 제한 없음:** 무료 플랜에서도 복잡한 조건 분기 및 다단계 노드 연결 가능 | **월 100 Tasks / 2-Step 제한:** 2단계 초과 및 조건 분기(Path) 사용 시 유료 플랜 전환 필수 |
| **5. 실행 로그(History) 확인** | **실시간 시각화 데이터 패킷:** 실행 단계별 데이터(Data Bundle) 입출력을 시각적으로 명확히 점검 가능 | **Task History 리스트:** 성공/실패 여부 및 단순 텍스트 데이터 로그 위주 제공 |

---

## 4. 장단점 정리 및 종합 의견

### 🟣 Make
* **장점:** 무료 플랜 범위가 넓고, 시각적 노드 구조라 복잡한 조건 분기(Router) 및 로직 설계에 매우 유리함.
* **단점:** 처음 사용하는 사용자에겐 UI 개념이 다소 복잡하게 느껴질 수 있음.
* **적합한 상황:** 데이터 흐름이 복잡하거나 조건 분기가 많은 업무, 비용 효율적으로 자동화를 구축하려는 경우.

### 🟠 Zapier
* **장점:** 설정 과정이 매우 직관적이고 연동되는 앱의 종류가 매우 풍부함.
* **단점:** 무료 플랜 제한이 엄격하여 조건 분기나 다단계 작업 구현 시 유료 결제가 필요함.
* **적합한 상황:** 빠르고 단순한 A $\rightarrow$ B 형태의 자동화를 원하거나, 비개발자 위주의 팀 환경.
