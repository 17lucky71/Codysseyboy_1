## 🎯 주요 학습 내용

### **Make의 강점**
- ⚡ 빠른 응답 (5초, Webhook 기반)
- 🔀 무한 분기 (Router)
- 💰 무료 플랜 충분 (1,000 ops/월)

### **Zapier의 강점**
- 📚 5,000+ 앱 통합
- 🧙 초보자 친화적 (마법사식)
- 🏢 엔터프라이즈급 신뢰성

### **AI 통합**
- 🤖 OpenAI GPT-4o 실제 사용
- 📝 프롬프트 엔지니어링
- 🔄 JSON 자동 파싱
