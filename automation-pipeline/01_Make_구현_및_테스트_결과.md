# 🚀 [프로젝트 1] Make를 이용한 자동화 구현 및 테스트 결과
 
## 📋 개요
 
"Google Forms 설문 응답 → 조건 분기(점수 기준) → Google Sheets 기록 + Discord 알림" 워크플로우를 **Make**에서 실제로 구현하고, 테스트 응답을 여러 번 제출해 정상 동작을 확인한 결과를 정리한 문서입니다.
 
---
 
## 1. 사용한 도구 및 리소스
 
- **자동화 플랫폼:** Make (make.com)
- **트리거:** Google Forms — "자동화_테스트설문" (테스트 전용으로 새로 생성한 설문지, 질문: "점수")
- **기록 대상:** Google Sheets — "자동화_실행기록" (시간 / 응답ID / 점수 / 응답내용 컬럼으로 새로 생성)
- **알림 대상:** Discord — "자동화_테스트" 서버의 "일반" 채널 (테스트 전용으로 새로 생성)
개인정보나 기존 업무에 쓰이던 폼·시트를 재사용하지 않고, 테스트만을 위한 새 리소스를 만들어 진행했습니다.
 
---
 
## 2. 시나리오 구성
 
```
[Google Forms] Watch Responses
        ↓
[Router] 조건 분기 (점수 >= 80 ?)
    ├─ 1st: 고득점 (점수 >= 80)
    │     ├─ Google Sheets - Add a Row
    │     └─ Discord - Send a Message (긴급 알림)
    │
    └─ 2nd: 그 외 (점수 < 80, 기본 경로)
          └─ Google Sheets - Add a Row
```
 
### 2.1 Google Forms 트리거
 
- 새로 만든 "자동화_테스트설문" 폼을 연결
- 새 응답이 제출되면 트리거가 실행되도록 설정
### 2.2 Router 조건
 
- 조건: 응답의 "점수" 값이 **80 이상**이면 1st 경로("고득점")로 분기
- 그 외의 경우 2nd 경로(기본/저득점)로 처리
### 2.3 Google Sheets 기록 (모든 경로 공통)
 
| 컬럼 | 값 |
|---|---|
| 시간 (A) | `now` (현재 시각) |
| 응답ID (B) | Google Forms 응답의 Response ID |
| 점수 (C) | 응답자가 입력한 점수 값 |
| 응답내용 (D) | (해당 폼에 추가 질문 없어 비워둠) |
 
### 2.4 Discord 알림 (고득점 경로만)
 
메시지 형식:
 
```
🚨 긴급 응답 수신!
점수: [응답 점수]
```
 
---
 
## 3. 실행 결과
 
실제로 폼에 여러 번 응답을 제출하며 테스트를 진행했습니다.
 
| 점수 | 분기 경로 | Google Sheets 기록 | Discord 알림 |
|---|---|---|---|
| 90 | 고득점 (1st) | ✅ 기록됨 | ✅ 발송됨 |
| 90 | 고득점 (1st) | ✅ 기록됨 | ✅ 발송됨 |
| 70 | 저득점 (2nd) | ✅ 기록됨 | ⏭️ 발송 안 됨 (정상) |
| 80 | 고득점 (1st) | ✅ 기록됨 | ✅ 발송됨 |
 
**결과 요약**
 
- 총 실행: 여러 차례, 에러 없이 100% 성공
- 고득점(≥80) 경로: Google Sheets 기록 + Discord 알림 정상 발송 확인
- 저득점(<80) 경로: Google Sheets에만 기록되고 Discord 알림은 발송되지 않음을 확인 (의도한 대로 동작)
### 3.1 테스트 응답 제출 화면 (스크린샷)
 
실제로 "자동화_테스트설문" 폼에 접속해 점수를 입력하고 제출한 과정입니다.
 
![점수 80 제출](./03-form-submit-80.png)
 
![점수 90 제출](./04-form-submit-90.png)
 
![응답 제출 완료 확인](./05-form-submitted-confirm.png)
 
점수를 입력하고 "제출" 버튼을 누르면 "응답이 기록되었습니다"라는 확인 화면이 뜨며, 이 시점에 Make의 Google Forms 트리거가 새 응답을 감지하여 시나리오가 실행됩니다.
 
### 3.2 Google Sheets 기록 결과 (스크린샷)
 
![Google Sheets 실행 기록](./01-sheets-result.png)
 
"자동화_실행기록" 스프레드시트에 실제 테스트 응답들이 시간/응답ID/점수 순으로 기록된 모습입니다. 점수 70(저득점)과 80·90(고득점) 응답이 모두 정상적으로 기록되어, 두 분기 경로 모두 Google Sheets 기록 액션이 정상 동작함을 확인할 수 있습니다.
 
### 3.3 Discord 알림 수신 결과 (스크린샷)
 
![Discord 알림 결과](./02-discord-result.png)
 
점수 90, 90, 80으로 제출한 고득점 응답에 대해서만 "🚨 긴급 응답 수신!" 메시지가 Discord 채널("자동화_테스트" 서버의 #일반)에 도착한 것을 확인할 수 있습니다. 점수 70(저득점) 응답에는 알림이 오지 않았으며, 이는 Router의 조건 분기가 의도한 대로 작동함을 보여줍니다.

## 4. 트러블슈팅 (실제로 겪은 문제와 해결 과정)
 
과제를 진행하며 실제로 겪었던 문제와 해결 방법을 정리했습니다.
 
1. **Google Forms 응답 필드 매핑 오류**
   같은 이름의 필드("Text Answers")가 두 군데(퀴즈 채점용 Grade 하위, 실제 응답값)에 존재해 처음에는 잘못된(빈) 값을 매핑했습니다. Router 조건이 항상 거짓으로 평가되어 모든 응답이 저득점 경로로만 빠지는 문제가 발생했고, 실제 응답 값이 들어있는 올바른 경로(`Answers.점수.textAnswers.answers[].value`)를 찾아 재매핑하여 해결했습니다.
2. **작업 중 새로고침으로 인한 미저장 시나리오 손실**
   시나리오를 정식으로 저장하기 전 실수로 새로고침하여 작업 내용이 사라질 뻔했으나, Make의 자동 복구(Recover unsaved changes) 기능으로 복구했습니다. 이후 매 단계마다 저장 버튼을 눌러 확인하는 습관을 들였습니다.

## 5. 과제 요구사항 충족 여부
 
- ✅ Trigger 1개 이상: Google Forms
- ✅ Action 2개 이상: Google Sheets, Discord
- ✅ 조건 분기 1개 이상: Router (점수 ≥80 기준)
- ✅ 양쪽 분기 경로 모두 실제 실행 확인 (고득점/저득점 각각 여러 회)
- ✅ 에러 없이 정상 동작 확인
