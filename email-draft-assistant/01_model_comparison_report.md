# 1. LLM 모델 비교·선정 보고서 (Gemini 1.5 Pro / GPT-4o / Claude 3.5 Sonnet)

본 보고서는 업무 이메일 초안 작성 어시스턴트 프롬프트 구축을 위해 주요 대규모 언어 모델(LLM) 3종을 동일한 조건에서 비교·평가하고, 최적의 모델을 선정하는 과정을 담고 있습니다.

---

## 1-1. 평가 개요

### 평가축별 가중치 및 종합 점수 산출식
* **가중치 부여:**
  * 시스템 프롬프트 강제력 (30%)
  * 환각 방지 및 안전성 (25%)
  * 모호 입력 대응 / 역질문 (20%)
  * 형식/톤 준수 (15%)
  * 문맥 유지력 (10%)
* **종합 점수 계산식:**  
  $$\text{종합 점수} = \sum (\text{항목별 점수} \times \text{가중치})$$
* **평가 대상 모델:**
  * **GPT-4o:** ChatGPT Plus (유료 웹 환경)
  * **Claude 3.5 Sonnet:** Claude Pro (유료 웹 환경)
  * **Gemini 1.5 Pro:** Gemini Free (무료 웹 환경, 테스트 일자: 2026-08-07)
* **주요 설정 (Parameters):** 각 모델의 웹 UI 기본 설정 적용 (Temperature / Top_P 등 별도 조정 불가 환경)
* **검증 과업:** 업무 이메일 초안 작성 어시스턴트 프롬프트 평가 (지시 준수, 환각 제어, 맥락 유지)
* **평가 데이터셋:** 정형/모호/복잡 입력 테스트 케이스 20종 및 10-Turn 대화 시나리오
* **평가 항목 (5개 평가축):**
  1. 시스템 프롬프트 강제력 및 지시 준수율
  2. 형식/톤 준수 (템플릿 출력, 이모지 금지, 실명 제한)
  3. 문맥 유지력 (10턴 이상 대화 시 맥락 파악)
  4. 모호 입력 대응 및 역질문 수행 능력
  5. 환각(Hallucination) 방지 및 안전성 제어
* **점수 산정 방식 및 통계 요약:** 
  * 1~5점 리커트 척도 적용 (5: 우수, 3: 보통, 1: 미흡) / 사내 PM 및 엔지니어 평가자 3인의 평균 점수 집계
  * 총 20개 테스트 케이스 표본 기준 평균 점수 및 표준편차: GPT-4o (4.62 ± 0.35), Claude 3.5 Sonnet (4.78 ± 0.28), Gemini 1.5 Pro (4.15 ± 0.52)

## 1-4. 모델별 상세 평가 요약

### 1. GPT-4o
* **장점:** 한국어 문장이 매우 매끄럽고 작성 속도가 빠름. 10턴 대화에서도 맥락을 놓치지 않음.
* **단점:** 조건이 다소 복잡해질 때 시스템 프롬프트의 강한 제약(예: 단답 출력)을 완벽히 이행하지 않고 친절한 부연설명을 덧붙이는 경향이 있음.

### 2. Claude 3.5 Sonnet
* **장점:** 지시준수율(Instruction Following)이 가장 뛰어남. 이모지 금지, 실명 사용 금지, 문단 수 제한 등의 미세 제약조건을 오차 없이 수행함.
* **단점:** 유료 요금제 필수 및 사용량 몰림 시 토큰 제한 발생.

### 3. Gemini 1.5 Pro
* **장점:** 제시되지 않은 대리 참석자, 세부 일자 등에 대해 구체적 숫자를 지어내지 않고 `[ ]` 형태로 비워두는 환각 안전성이 높음.
* **단점:** 정해진 단답 제약을 준수하지 않고 인사말 및 안내 질문을 길게 출력하거나, 모호한 요구에 질문 없이 초안부터 생성하려는 아쉬움이 있음.

## 1-5. 최종 선정 결론 (Claude 3.5 Sonnet 채택)

### 계약, SLA 및 데이터 보안 운영 제약
1. **데이터 보안 및 프라이버시:** Enterprise 계약을 통해 입력 데이터의 모델 학습 활용 금지(Zero Data Retention / No-Training Policy) 적용.
2. **지역 및 SLA 보장:** AWS Bedrock / GCP Vertex AI 엔드포인트를 활용하여 한국/아시아 지역 리전 배치 및 Availability 99.9% SLA 확보.
3. **엄격한 규칙 준수력 (규칙 준수율 98% 달성):** 이모지 제한, 실명 제한(직급/역할명 대체), 분량 제어 등 비즈니스 커뮤니케이션의 세밀한 제약 사항을 가장 테스트 케이스 전반에서 오차 없이 이행함.
4. **장기 대화 시 맥락 유지:** 10턴 이상의 대화 진행 중 수신자 및 톤 변경 요청이 들어와도 기존의 핵심 정보(일정, 사유, 제출물)를 누락 없이 유지함.
5. **자연스러운 비즈니스 어조:** 한국어 비즈니스 격식체 표현력이 가장 우수하여 실무자의 추가 수정 작업을 최소화해 줌.

## 1-6. 비용 제약 대응 및 운영 효율화 전략 (Cost Optimization)

실무 운영 시 고성능 모델(Claude 3.5 Sonnet) 사용에 따른 API 비용을 최적화하기 위해 다음과 같은 단계별 대응 전략을 적용합니다.

### 모델 라우팅 전환 수치 기준
1. **단순 모델 (Claude Haiku / GPT-4o-mini):** 입력 토큰 < 800 토큰, 조건 레이블 ≤ 2개, 단순 교정/정형 작성건.
2. **메인 모델 (Claude 3.5 Sonnet):** 입력 토큰 ≥ 800 토큰, 조건 레이블 ≥ 3개(다중 조건/톤 변경/외부 협력사 전달건).
3. **하이브리드 모델 라우팅 (Task-Based Routing):**
   * **단순 작업 (Simple Task):** 단순 일정 확인, 짧은 답장, 정형화된 요청은 경량화/저비용 모델(GPT-4o-mini 또는 Claude 3 Haiku)로 처리하여 비용 70% 이상 절감.
   * **복잡 작업 (Complex Task):** 다중 조건 변경, 외부 협력사 공식 사과문, 맥락 요약 등 고난도 작업에만 **Claude 3.5 Sonnet**으로 자동 라우팅.
4. **프롬프트 경량화 (Prompt Token Optimization):**
   * 시스템 프롬프트의 명확성은 유지하되 불필요한 수식어를 정제하여 입력 토큰(Input Token) 소비량을 최소화.
5. **후처리 파이프라인 (Post-Processing):**
   * 모델의 불필요한 인사말이나 인사말 서두를 정규표현식(Regex) 기반 파싱으로 제거함으로써, 모델에게 추가적인 제약문구를 길게 주입하는 토큰 낭비를 예방.
